高数Ⅰ（2026-9-18）

第一部分：集合论基础

1. 集合的基本定义

  • 有限集与无限集：若集合 $A$ 由有限个元素组成，称 $A$ 为有限集；否则称无限（穷）集。
  • 可数集与不可数集：
    • 与正整数集一一对应的集合称为可数集。
    • 不是可数集的无穷集称为不可数集。
  • 势（基数）的定义：
    • 若 $A$ 与 $B$ 一一对应，则称 $A$ 与 $B$ 的势相同，记作 $\overline{\overline{A}} = \overline{\overline{B}}$。
    • 若 $A$ 为有限集，则 $A$ 的势为 $A$ 的元素个数。例：$A = {3, 5, 7}$，则 $\overline{\overline{A}} = 3$。

2. 常见集合的势

  • 自然数集：$\overline{\overline{\mathbb{N}}} = \aleph_0$。
  • 可数集 $A$ 与自然数集一一对应 $\implies \overline{\overline{A}} = \aleph_0$。
  • 实例：函数 $f: \mathbb{N} \rightarrow 2\mathbb{N}$，映射 $n \rightarrow 2n$。可得 $\overline{\overline{\mathbb{Z}}} = \overline{\overline{2\mathbb{N}}} = \overline{\overline{\mathbb{N}}} = \aleph_0$。
  • 有理数与无理数：
    • 有理数集为可数集，$\overline{\overline{\mathbb{Q}}} = \aleph_0$。
    • 无理数集与实数集一一对应，$\therefore \overline{\overline{\mathbb{R}}} = \overline{\overline{\mathbb{Q}^c}} = \aleph$（或 $c$）。
    • 注：可证可数集与实数集不一一对应，实数集的势大于可数集。

3. 幂集及其势（康托尔定理）

  • 幂集定义：$A$ 的幂集是由 $A$ 的所有子集组成的集合，记作 $2^A$。
  • 有限集幂集的性质：
    • 例：$A = {2, 3}$，则 $2^A = {\emptyset, A, {2}, {3}}$，此时 $\overline{\overline{A}} = 2$，$\overline{\overline{2^A}} = 2^2 = 2^{\overline{\overline{A}}}$。
    • 例：$A = {2, 3, 4}$，则 $\overline{\overline{A}} = 3$，$\overline{\overline{2^A}} = 8 = 2^{\overline{\overline{A}}}$。
    • 结论：若 $\overline{\overline{A}} = n$，则 $\overline{\overline{2^A}} = 2^n$。
  • 无限集幂集的性质：
    • 若 $\overline{\overline{A}} = \aleph_0$，则 $\overline{\overline{2^A}} = \aleph$（即 $2^{\aleph_0} = c$）。
    • 核心定理：$\overline{\overline{A}} < \overline{\overline{2^A}}$（任何集合的幂集的势都严格大于原集合的势）。
    • 推论：没有最大势的集合，最小无穷集的势为 $\aleph_0$。

4. 希尔伯特第一问题与连续统假设（CH）

  • 问题：是否存在集合使其势介于 $\aleph_0$ 与 $\aleph$ 之间？
  • 连续统假设：不存在集合的势介于 $\aleph_0$ 与 $\aleph$ 之间。
  • 可数集的表示：若 $A$ 为可数集，则 $A$ 可表示为 $A = {a_1, a_2, a_3, \cdots, a_n, \cdots}$。

5. 集合的差集与补集

  • 差集：$A-B$ 表示属于 $A$ 但不属于 $B$ 的元素集合。当 $A \cap B = \emptyset$ 时，$A-B = A$。
  • 补集：若 $A \subset \mathbb{R}$，则 $R-A = A^C$。无理数集 $\mathbb{Q}^C = \mathbb{R} - \mathbb{Q}$。

第二部分：具体函数与映射实例

1. 反函数及其求法

  • 一一对应与反函数：只有双射才有反函数。
    • 例：$y = \sin x$ 在 $[-\frac{\pi}{2}, \frac{\pi}{2}] \to [-1, 1]$ 上是双射，存在反函数 $x = \arcsin y: [-1, 1] \to [-\frac{\pi}{2}, \frac{\pi}{2}]$。
    • 数值验证：$\sin\frac{\pi}{2}=1 \implies \arcsin 1 = \frac{\pi}{2}$；$\arcsin\frac{1}{2} = \frac{\pi}{6}$；$\arcsin\frac{\sqrt{3}}{2} = \frac{\pi}{3}$。
  • 求反函数例题：
    • 例1：求 $y = \sqrt{x} (x \ge 0)$ 的反函数。解：$x = y^2 \ (y \ge 0)$。
    • 例2：求分段函数 $f(x) = \begin{cases} 2x+1, & x \le 1 \ x^2+2, & 1 < x \le 2 \ 2^x+6, & x > 2 \end{cases}$ 的反函数 $f^{-1}(x)$。
      • ① $x \le 1$：$y = 2x+1$，且 $y \le 3$。$\therefore x = \frac{y-1}{2}, y \le 3$。
      • ② $1 < x \le 2$：$y = x^2+2$，且 $3 \le y \le 6$。$\therefore x = \sqrt{y-2}$。
      • ③ $x > 2$：$y = 2^x+6$，且 $y > 10$。$\therefore x = \log_2(y-6)$。
      • 结论：$y = \begin{cases} \frac{x-1}{2}, & x \le 3 \ \sqrt{x-2}, & 3 \le x \le 6 \ \log_2(x-6), & x > 6 \end{cases}$

2. 几个特殊函数

  • ① 绝对值函数：$y = |x|$。
  • ② 符号函数：$y = \text{sgn}(x) = \begin{cases} 1, & x > 0 \ 0, & x = 0 \ -1, & x < 0 \end{cases}$
  • ③ 取整函数：$y = [x]$，表示不大于 $x$ 的最大整数（$n \le x < n+1$ 时 $[x]=n$）。例：$[1.5]=1, [8.73]=8, [-7.4]=-8, [0.37]=0$。
  • ④ 狄利克雷函数：$y = \begin{cases} 1, & x \in \mathbb{Q} \ 0, & x \in \mathbb{Q}^C \end{cases}$，定义域 $x \in (-\infty, +\infty)$。
  • ⑤ 黎曼函数：$R(x) = \begin{cases} \frac{1}{m}, & x = \frac{n}{m}, (m, n)=1, m, n \in \mathbb{Z}^+ \ 0, & x \in \mathbb{Q}^C \ 1, & x = 0, 1 \end{cases}$，定义域 $x \in [0, 1]$。

3. 函数的四则运算

设函数 $f$ 的定义域为 $I_1$，$g$ 的定义域为 $I_2$。

  • ① $(f \pm g)(x) = f(x) \pm g(x)$，定义域 $I = I_1 \cap I_2$
  • ② $(f \cdot g)(x) = f(x) \cdot g(x)$，定义域 $I = I_1 \cap I_2$
  • ③ $(\frac{f}{g})(x) = \frac{f(x)}{g(x)}$，定义域 $I = I_1 \cap I_2$ 且 $g(x) \neq 0$

第三部分：复合函数与反函数代数性质

1. 复合函数进阶例题

例1：已知 $f(x) = \begin{cases} 2-x, & x \le 0 \ 2+x, & x > 0 \end{cases}$，$g(x) = \begin{cases} x^2, & x \le 0 \ -x, & x \ge 0 \end{cases}$。求 $g(f(x))$。

  • 解析：
    因为当 $x \le 0$ 时，$f(x) = 2-x \ge 2 > 0$；当 $x > 0$ 时，$f(x) = 2+x > 2 > 0$。
    所以 $f(x)$ 恒大于 0。代入 $g(x)$ 的表达式，应使用 $g(x) = -x$ 这一分段。
    $\therefore g(f(x)) = -f(x) = \begin{cases} -(2-x), & x \le 0 \ -(2+x), & x > 0 \end{cases} = \begin{cases} x-2, & x \le 0 \ -x-2, & x > 0 \end{cases}$

例2：已知 $f(x) = \begin{cases} x^2, & x \le 0 \ \ln x, & x > 0 \end{cases}$，$g(x) = \begin{cases} 1, & -1 \le x < 0 \ 2x+1, & 0 \le x \le 1 \end{cases}$。求 $g(f(x))$。

  • 解析：
    分段讨论，将 $f(x)$ 视为整体代入 $g(x)$ 的定义域条件：
    ① 当 $-1 \le f(x) < 0$ 时：只能由 $x > 0$ 段提供，即 $-1 \le \ln x < 0 \implies \frac{1}{e} \le x < 1$。
    ② 当 $0 \le f(x) \le 1$ 时：
    * 若 $x \le 0$：$0 \le x^2 \le 1 \implies -1 \le x \le 0$。
    * 若 $x > 0$：$0 \le \ln x \le 1 \implies 1 \le x \le e$。
    $\therefore g(f(x)) = \begin{cases} 1, & \frac{1}{e} \le x < 1 \ 2x^2+1, & -1 \le x \le 0 \ 2\ln x+1, & 1 \le x \le e \end{cases}$
    补充定义：自然对数 $\ln x = \log_e x$，其中 $e \approx 2.718$。

2. 反函数的严格代数定义（映射视角）

  • 定义：若 $f: A \to B$ 是一一对应（双射），则存在反函数 $f^{-1}: B \to A$。
  • 核心恒等式：
    • $f(f^{-1}(x)) = x, \quad x \in B$
    • $f^{-1}(f(x)) = x, \quad x \in A$
  • 恒等映射表示：
    • $I_B = f \circ f^{-1}: B \to B$
    • $I_A = f^{-1} \circ f: A \to A$
  • 实例：$\sin(\arcsin x) = x$（$x \in [-1, 1]$），$\arctan(\tan x) = x$（$x \in (-\frac{\pi}{2}, \frac{\pi}{2})$）。
