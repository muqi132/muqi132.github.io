第一部分：集合论基础

1. 集合的基本定义

  • 有限集与无限集：若集合 AAA 由有限个元素组成，称 AAA 为有限集；否则称无限（穷）集。
  • 可数集与不可数集：
    • 与正整数集一一对应的集合称为可数集。
    • 不是可数集的无穷集称为不可数集。
  • 势（基数）的定义：
    • 若 AAA 与 BBB 一一对应，则称 AAA 与 BBB 的势相同，记作 A‾‾=B‾‾\overline{\overline{A}} = \overline{\overline{B}}A=B。
    • 若 AAA 为有限集，则 AAA 的势为 AAA 的元素个数。例：A={3,5,7}A = \{3, 5, 7\}A={3,5,7}，则 A‾‾=3\overline{\overline{A}} = 3A=3。

2. 常见集合的势

  • 自然数集：N‾‾=ℵ0\overline{\overline{\mathbb{N}}} = \aleph_0N=ℵ0​。
  • 可数集 AAA 与自然数集一一对应   ⟹  A‾‾=ℵ0\implies \overline{\overline{A}} = \aleph_0⟹A=ℵ0​。
  • 实例：函数 f:N→2Nf: \mathbb{N} \rightarrow 2\mathbb{N}f:N→2N，映射 n→2nn \rightarrow 2nn→2n。可得 Z‾‾=2N‾‾=N‾‾=ℵ0\overline{\overline{\mathbb{Z}}} = \overline{\overline{2\mathbb{N}}} = \overline{\overline{\mathbb{N}}} = \aleph_0Z=2N=N=ℵ0​。
  • 有理数与无理数：
    • 有理数集为可数集，Q‾‾=ℵ0\overline{\overline{\mathbb{Q}}} = \aleph_0Q​​=ℵ0​。
    • 无理数集与实数集一一对应，∴R‾‾=Qc‾‾=ℵ\therefore \overline{\overline{\mathbb{R}}} = \overline{\overline{\mathbb{Q}^c}} = \aleph∴R=Qc​​=ℵ（或 ccc）。
    • 注：可证可数集与实数集不一一对应，实数集的势大于可数集。

3. 幂集及其势（康托尔定理）

  • 幂集定义：AAA 的幂集是由 AAA 的所有子集组成的集合，记作 2A2^A2A。
  • 有限集幂集的性质：
    • 例：A={2,3}A = \{2, 3\}A={2,3}，则 2A={∅,A,{2},{3}}2^A = \{\emptyset, A, \{2\}, \{3\}\}2A={∅,A,{2},{3}}，此时 A‾‾=2\overline{\overline{A}} = 2A=2，2A‾‾=22=2A‾‾\overline{\overline{2^A}} = 2^2 = 2^{\overline{\overline{A}}}2A=22=2A。
    • 例：A={2,3,4}A = \{2, 3, 4\}A={2,3,4}，则 A‾‾=3\overline{\overline{A}} = 3A=3，2A‾‾=8=2A‾‾\overline{\overline{2^A}} = 8 = 2^{\overline{\overline{A}}}2A=8=2A。
    • 结论：若 A‾‾=n\overline{\overline{A}} = nA=n，则 2A‾‾=2n\overline{\overline{2^A}} = 2^n2A=2n。
  • 无限集幂集的性质：
    • 若 A‾‾=ℵ0\overline{\overline{A}} = \aleph_0A=ℵ0​，则 2A‾‾=ℵ\overline{\overline{2^A}} = \aleph2A=ℵ（即 2ℵ0=c2^{\aleph_0} = c2ℵ0​=c）。
    • 核心定理：A‾‾<2A‾‾\overline{\overline{A}} < \overline{\overline{2^A}}A<2A（任何集合的幂集的势都严格大于原集合的势）。
    • 推论：没有最大势的集合，最小无穷集的势为 ℵ0\aleph_0ℵ0​。

4. 希尔伯特第一问题与连续统假设（CH）

  • 问题：是否存在集合使其势介于 ℵ0\aleph_0ℵ0​ 与 ℵ\alephℵ 之间？
  • 连续统假设：不存在集合的势介于 ℵ0\aleph_0ℵ0​ 与 ℵ\alephℵ 之间。
  • 可数集的表示：若 AAA 为可数集，则 AAA 可表示为 A={a1,a2,a3,⋯ ,an,⋯ }A = \{a_1, a_2, a_3, \cdots, a_n, \cdots\}A={a1​,a2​,a3​,⋯,an​,⋯}。

5. 集合的差集与补集

  • 差集：A−BA-BA−B 表示属于 AAA 但不属于 BBB 的元素集合。当 A∩B=∅A \cap B = \emptysetA∩B=∅ 时，A−B=AA-B = AA−B=A。
  • 补集：若 A⊂RA \subset \mathbb{R}A⊂R，则 R−A=ACR-A = A^CR−A=AC。无理数集 QC=R−Q\mathbb{Q}^C = \mathbb{R} - \mathbb{Q}QC=R−Q。
