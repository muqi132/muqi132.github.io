1. 数列极限的定义（ϵ−N\epsilon - Nϵ−N 语言）

  • 定义：对于数列 {xn}\{x_n\}{xn​}，若 ∀ϵ>0,∃N∈N,∀n>N\forall \epsilon > 0, \exists N \in \mathbb{N}, \forall n > N∀ϵ>0,∃N∈N,∀n>N，有 ∣xn−A∣<ϵ|x_n - A| < \epsilon∣xn​−A∣<ϵ，则称常数 AAA 为数列 {xn}\{x_n\}{xn​} 的极限。

第四部分：数列极限的性质（图12）

极限的唯一性定理

  • 定理：若数列 {xn}\{x_n\}{xn​} 收敛，则其极限值唯一。
  • 证明（反证法）：
    • 假设 lim⁡n→∞xn=A\lim_{n \to \infty} x_n = Alimn→∞​xn​=A，且 lim⁡n→∞xn=B\lim_{n \to \infty} x_n = Blimn→∞​xn​=B，且 A≠BA \neq BA=B。
    • 根据定义，∀ϵ>0,∃N1∈N,∀n>N1,∣xn−A∣<ϵ\forall \epsilon > 0, \exists N_1 \in \mathbb{N}, \forall n > N_1, |x_n - A| < \epsilon∀ϵ>0,∃N1​∈N,∀n>N1​,∣xn​−A∣<ϵ；同样地，∃N2∈N,∀n>N2,∣xn−B∣<ϵ\exists N_2 \in \mathbb{N}, \forall n > N_2, |x_n - B| < \epsilon∃N2​∈N,∀n>N2​,∣xn​−B∣<ϵ。
    • 取 N=max⁡(N1,N2)N = \max(N_1, N_2)N=max(N1​,N2​)，当 n>Nn > Nn>N 时，两式均成立。
    • 利用三角不等式：
      ∣A−B∣=∣A−xn+xn−B∣≤∣A−xn∣+∣xn−B∣|A - B| = |A - x_n + x_n - B| \le |A - x_n| + |x_n - B|∣A−B∣=∣A−xn​+xn​−B∣≤∣A−xn​∣+∣xn​−B∣
    • ⚠️【错误指出与修正】 黑板上老师的板书在这最后一步出现了笔误：
      • 老师板书为：<ϵ2+ϵ2=ϵ< \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon<2ϵ​+2ϵ​=ϵ。
      • 错误原因：前面的假设是 ∣xn−A∣<ϵ|x_n - A| < \epsilon∣xn​−A∣<ϵ 和 ∣xn−B∣<ϵ|x_n - B| < \epsilon∣xn​−B∣<ϵ，并没有说是 <ϵ2< \frac{\epsilon}{2}<2ϵ​，直接加和应该是 <2ϵ< 2\epsilon<2ϵ。
      • 正确证明：根据极限定义，我们可以在假设时明确选取某个特定的值，例如任取 ϵ0=∣A−B∣2\epsilon_0 = \frac{|A-B|}{2}ϵ0​=2∣A−B∣​。则存在 N1N_1N1​，当 n>N1n>N_1n>N1​ 时 ∣xn−A∣<∣A−B∣2|x_n-A| < \frac{|A-B|}{2}∣xn​−A∣<2∣A−B∣​；存在 N2N_2N2​，当 n>N2n>N_2n>N2​ 时 ∣xn−B∣<∣A−B∣2|x_n-B| < \frac{|A-B|}{2}∣xn​−B∣<2∣A−B∣​。取 N=max⁡(N1,N2)N=\max(N_1, N_2)N=max(N1​,N2​)，则当 n>Nn>Nn>N 时有：
        ∣A−B∣≤∣xn−A∣+∣xn−B∣<∣A−B∣2+∣A−B∣2=∣A−B∣|A - B| \le |x_n - A| + |x_n - B| < \frac{|A-B|}{2} + \frac{|A-B|}{2} = |A-B|∣A−B∣≤∣xn​−A∣+∣xn​−B∣<2∣A−B∣​+2∣A−B∣​=∣A−B∣
        这就推出了 ∣A−B∣<∣A−B∣|A-B| < |A-B|∣A−B∣<∣A−B∣，产生矛盾。因此假设不成立，必有 A=BA = BA=B。
    • 结论：∴A=B\therefore A = B∴A=B。
