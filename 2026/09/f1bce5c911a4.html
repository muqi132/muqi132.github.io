高数Ⅰ（2026-9-21）

第一部分：隐函数、参数方程与极坐标

1. 隐函数方程

  • 定义：$F(x, y) = 0$
  • 示例：
    • 圆：$x^2 + y^2 = 1$
    • 复杂方程：$\arctan\sqrt{y+x^2} + e^{2xy} - 2 = 0$

2. 参数方程

  • 定义：$\begin{cases} x = x(t) \ y = y(t) \end{cases} , \quad t \in [\alpha, \beta]$
  • 示例（摆线/旋轮线）：
    $\begin{cases} x = a(t - \sin t) \ y = a(1 - \cos t) \end{cases} , \quad t \in [0, 2\pi]$
    • [补充说明] 该摆线在一个周期内的跨度为 $2\pi a$，最高点高度为 $2a$。

3. 将隐函数化为参数方程

  • 椭圆：$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \implies \begin{cases} x = a\cos t \ y = b\sin t \end{cases} , \quad t \in [0, 2\pi]$
  • 双曲线：$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \implies \begin{cases} x = a\sec t \ y = b\tan t \end{cases} , \quad t \in (-\frac{\pi}{2}, \frac{\pi}{2})$
  • [补充说明] 老师板书右侧列出了三角恒等式作为配凑基础：$\sin^2x + \cos^2x = 1$，$\tan^2x + 1 = \sec^2x$，$\sec^2x - \tan^2x = 1$。

4. 极坐标

  • 定义：$r = r(\theta), \quad \theta \in [\alpha, \beta], \quad r = |OP| \ge 0$
  • 直角坐标与极坐标的互化：
    • 直角坐标 $\to$ 极坐标：$x = r\cos\theta, \quad y = r\sin\theta$
    • 极坐标 $\to$ 直角坐标：$r = \sqrt{x^2+y^2}, \quad \tan\theta = \frac{y}{x}$
  • 极坐标化为参数方程：
    $r = r(\theta) \implies \begin{cases} x = r(\theta)\cos\theta \ y = r(\theta)\sin\theta \end{cases}$
  • 例题 1：心形线
    • 方程：$r = a(1 - \cos\theta) \quad (a > 0)$，求参数方程并作图。
    • 解：$\begin{cases} x = a(1-\cos\theta)\cos\theta \ y = a(1-\cos\theta)\sin\theta \end{cases} , \quad \theta \in [0, 2\pi]$
    • [补充说明] 板书右侧画出了心形线图形，并标注了几个关键点：$\theta=0, r=0$；$\theta=\frac{\pi}{3}, r=\frac{a}{2}$；$\theta=\frac{\pi}{2}, r=a$。
  • 直角坐标方程化为极坐标方程：
    令 $x = r\cos\theta, y = r\sin\theta$，代入 $F(x,y)=0 \implies F(r\cos\theta, r\sin\theta)=0$，解出 $r=r(\theta)$。
  • 例题 2：双纽线
    • 方程：$(x^2+y^2)^2 = a^2(x^2-y^2)$
    • 解：代入 $x = r\cos\theta, y = r\sin\theta$ 得：
      $(r^2)^2 = a^2(r^2\cos^2\theta - r^2\sin^2\theta) = a^2 r^2 \cos 2\theta$
      $\therefore r = a\sqrt{\cos 2\theta}$
    • 定义域：需满足 $r \ge 0 \implies \cos 2\theta \ge 0$。
      $-\frac{\pi}{2} + 2k\pi \le 2\theta \le \frac{\pi}{2} + 2k\pi \implies -\frac{\pi}{4} + k\pi \le \theta \le \frac{\pi}{4} + k\pi$。
      [补充说明] 板书中给出了 $\theta$ 的具体范围：$\theta \in [-\frac{\pi}{4}, \frac{\pi}{4}] \cup [\frac{3\pi}{4}, \frac{5\pi}{4}]$。右侧画出了“无穷大/双纽线”形状的图形。

第二部分：数列的定义与基本性质（图7-图8）

1. 数列的定义

  • 数列是定义在正整数集上的函数：$f: \mathbb{N}^+ \to \mathbb{R}$
  • 对应关系：$n \to x_n$，记作 ${x_n}$。

2. 单调性

  • 单调递增：$\forall n \in \mathbb{N}^+, x_n \le x_{n+1}$，记作 $x_n \uparrow$。（严格单调递增：$x_n < x_{n+1}$）
  • 单调递减：$\forall n \in \mathbb{N}^+, x_n \ge x_{n+1}$，记作 $x_n \downarrow$。（严格单调递减：$x_n > x_{n+1}$）
  • 例题：
    • $x_n = \frac{2}{n} \downarrow$
    • $x_n = \cos(\cos\frac{1}{n}) \downarrow$ [补充说明] 因为 $\frac{1}{n} \in (0,1]$ 递减，$\cos x$ 在 $(0,1]$ 上递减，复合后递增？不对，$\frac{1}{n}$递减，$\cos(1/n)$递增，再套一个$\cos$在$(0,1]$上递减，所以整体递减。
    • $x_n = 1 - \sin\frac{1}{n} \uparrow$

3. 有界性

  • 有界：$\exists M > 0, \forall n \in \mathbb{N}^+, |x_n| \le M$。
  • 无界：$\forall M > 0, \exists n_0 \in \mathbb{N}^+, |x_{n_0}| > M$。

第三部分：数列极限的定义与验证（图9-图11）

1. 数列极限的定义（$\epsilon - N$ 语言）

  • 定义：对于数列 ${x_n}$，若 $\forall \epsilon > 0, \exists N \in \mathbb{N}, \forall n > N$，有 $|x_n - A| < \epsilon$，则称常数 $A$ 为数列 ${x_n}$ 的极限。
  • 记作：$\lim_{n \to \infty} x_n = A$ 或 $x_n \to A \ (n \to \infty)$。
  • 发散：若 ${x_n}$ 没有极限，称其发散。
  • 几何意义：在数轴上，从第 $N$ 项开始，所有的点 $x_{N+1}, x_{N+2}, \dots$ 都落在邻域 $(A-\epsilon, A+\epsilon)$ 内。
  • 关于 $N$ 的性质：
    • ① $N = N(\epsilon)$，依赖于 $\epsilon$。
    • ② $N$ 不唯一。若 $N’ > N$，则 $N’$ 也可以作为满足条件的项数。

2. 极限的验证例题

例题 1：验证 $\lim_{n \to \infty} \frac{1}{n} = 0$

  • 分析：$\forall \epsilon > 0$，要使 $|\frac{1}{n} - 0| = \frac{1}{n} < \epsilon$，只需 $n > \frac{1}{\epsilon}$。
  • 证明：取 $N = [\frac{1}{\epsilon}] + 1$。则 $\forall n > N$，有 $|\frac{1}{n} - 0| < \epsilon$。

例题 2：验证 $\lim_{n \to \infty} q^n = 0 \quad (|q| < 1)$

  • 分析：$\forall \epsilon > 0$（取 $0 < \epsilon < 1$），要使 $|q^n - 0| = |q|^n < \epsilon$。
  • 两边取对数（注意 $\lg|q| < 0$，不等号变号）：$n \lg|q| < \lg\epsilon \implies n > \frac{\lg\epsilon}{\lg|q|}$。
  • 证明：取 $N = [\frac{\lg\epsilon}{\lg|q|}]$，则 $\forall n > N$，有 $|q^n - 0| < \epsilon$。

例题 3：验证 $\lim_{n \to \infty} \frac{5n^2+n-2}{3n^2-2} = \frac{5}{3}$

  • 分析：$\forall \epsilon > 0$，要 $|\frac{5n^2+n-2}{3n^2-2} - \frac{5}{3}| < \epsilon$。
  • 化简放缩（图11右侧）：
    $|\frac{3(5n^2+n-2) - 5(3n^2-2)}{3(3n^2-2)}| = |\frac{3n+4}{3(3n^2-2)}| \le \frac{3n+n}{3(2n^2)} = \frac{4n}{6n^2} = \frac{2}{3n} < \epsilon$
  • [补充说明] 板书左侧有 $n>1$ 时的放缩过程，最终得到 $n > \frac{2}{3\epsilon}$。
  • 证明：取 $N = [\frac{2}{3\epsilon}] + 1$，即可得证。

第四部分：数列极限的性质（图12）

极限的唯一性定理

  • 定理：若数列 ${x_n}$ 收敛，则其极限值唯一。
  • 证明（反证法）：
    • 假设 $\lim_{n \to \infty} x_n = A$，且 $\lim_{n \to \infty} x_n = B$，且 $A \neq B$。
    • 根据定义，$\forall \epsilon > 0, \exists N_1 \in \mathbb{N}, \forall n > N_1, |x_n - A| < \epsilon$；同样地，$\exists N_2 \in \mathbb{N}, \forall n > N_2, |x_n - B| < \epsilon$。
    • 取 $N = \max(N_1, N_2)$，当 $n > N$ 时，两式均成立。
    • 利用三角不等式：
      $|A - B| = |A - x_n + x_n - B| \le |A - x_n| + |x_n - B|$
    • ⚠️【错误指出与修正】 黑板上老师的板书在这最后一步出现了笔误：
      • 老师板书为：$< \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon$。
      • 错误原因：前面的假设是 $|x_n - A| < \epsilon$ 和 $|x_n - B| < \epsilon$，并没有说是 $< \frac{\epsilon}{2}$，直接加和应该是 $< 2\epsilon$。
      • 正确证明：根据极限定义，我们可以在假设时明确选取某个特定的值，例如任取 $\epsilon_0 = \frac{|A-B|}{2}$。则存在 $N_1$，当 $n>N_1$ 时 $|x_n-A| < \frac{|A-B|}{2}$；存在 $N_2$，当 $n>N_2$ 时 $|x_n-B| < \frac{|A-B|}{2}$。取 $N=\max(N_1, N_2)$，则当 $n>N$ 时有：
        $|A - B| \le |x_n - A| + |x_n - B| < \frac{|A-B|}{2} + \frac{|A-B|}{2} = |A-B|$
        这就推出了 $|A-B| < |A-B|$，产生矛盾。因此假设不成立，必有 $A = B$。
    • 结论：$\therefore A = B$。
