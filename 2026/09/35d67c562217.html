高数Ⅰ（2026-9-28）

一、 数列极限的计算方法

1. 夹逼定理（求和式极限）

例1：求 $\lim_{n \to \infty} \left( \frac{1}{3n^2+2n+1} + \frac{2}{3n^2+2n+2} + \dots + \frac{n}{3n^2+2n+n} \right)$

  • 解析：令原式为 $x_n$。利用放缩法，将分母统一放大或缩小。
    • 分母全部取最大（$3n^2+2n+n$），则和式最小：$\frac{1+2+\dots+n}{3n^2+2n+n} \le x_n$
    • 分母全部取最小（$3n^2+2n+1$），则和式最大：$x_n \le \frac{1+2+\dots+n}{3n^2+2n+1}$
  • 化简两端：$\frac{\frac{1}{2}n(n+1)}{3n^2+2n+n} = \frac{\frac{1}{2}n^2 + \frac{1}{2}n}{3n^2+3n}$ 与 $\frac{\frac{1}{2}n(n+1)}{3n^2+2n+1}$。
  • 求极限：$\lim_{n \to \infty} \frac{\frac{1}{2}n(n+1)}{3n^2+2n+n} = \frac{1}{6}$，$\lim_{n \to \infty} \frac{\frac{1}{2}n(n+1)}{3n^2+2n+1} = \frac{1}{6}$。
  • 结论：由夹逼定理，原极限 $= \frac{1}{6}$。
  • （纠正：板书过程正确，但极限系数为 $\frac{1}{2}/3 = \frac{1}{6}$）

2. 裂项相消法

例2：求 $\lim_{n \to \infty} \left( \frac{1}{1\cdot3} + \frac{1}{3\cdot5} + \dots + \frac{1}{(2n-1)(2n+1)} \right)$

  • 解析：利用裂项公式 $\frac{1}{(2n-1)(2n+1)} = \frac{1}{2} \left( \frac{1}{2n-1} - \frac{1}{2n+1} \right)$。
  • 展开：原式 $= \lim_{n \to \infty} \frac{1}{2} \left[ \left(1 - \frac{1}{3}\right) + \left(\frac{1}{3} - \frac{1}{5}\right) + \dots + \left(\frac{1}{2n-1} - \frac{1}{2n+1}\right) \right]$
  • 化简：$= \lim_{n \to \infty} \frac{1}{2} \left( 1 - \frac{1}{2n+1} \right) = \frac{1}{2}$。

3. Stolz 定理

  • 定理：设 ${y_n}$ 严格单调递增，且 $\lim_{n \to \infty} y_n = \infty$，若 $\lim_{n \to \infty} \frac{x_{n+1} - x_n}{y_{n+1} - y_n} = A$，则 $\lim_{n \to \infty} \frac{x_n}{y_n} = A$。

  • 等价形式：有时也可写作 $\lim_{n \to \infty} \frac{y_n - y_{n-1}}{x_n - x_{n-1}} = A$。

  • 常用推论：$\lim_{n \to \infty} x_n = A \iff \lim_{n \to \infty} x_{n+1} = A$。

  • Stolz 定理应用 1：求 $\lim_{n \to \infty} \frac{1}{n} \left( 1 + \frac{1}{2} + \dots + \frac{1}{n} \right)$。

    • 令 $x_n = 1 + \frac{1}{2} + \dots + \frac{1}{n}$，$y_n = n$。
    • 由 Stolz 定理：$\lim_{n \to \infty} \frac{x_n - x_{n-1}}{y_n - y_{n-1}} = \lim_{n \to \infty} \frac{1/n}{1} = 0$。
    • 所以原极限 $= 0$。

  • Stolz 定理应用 2：求 $\lim_{n \to \infty} \frac{n}{a^n} \ (a > 1)$。

    • 由 Stolz 定理：$\lim_{n \to \infty} \frac{n - (n-1)}{a^n - a^{n-1}} = \lim_{n \to \infty} \frac{1}{a^{n-1}(a-1)} = 0$。

二、 极限存在准则与重要极限

1. 单调有界准则

定理：任何单调递增有上界（或单调递减有下界）的数列必有极限。

2. 重要极限 $e$ 的证明

  • 例3：证明 $x_n = (1 + \frac{1}{n})^n$ 收敛。
    • 证明单调递增：利用 A-G 不等式（算术-几何平均值不等式）。
      $x_n = \underbrace{(1+\frac{1}{n}) \cdot (1+\frac{1}{n}) \dots (1+\frac{1}{n})}{n\text{个}} \cdot 1
      \le \left( \frac{n(1+\frac{1}{n}) + 1}{n+1} \right)^{n+1} = \left( \frac{n+2}{n+1} \right)^{n+1} = \left( 1 + \frac{1}{n+1} \right)^{n+1} = x      {n+1}$。
      所以 $x_n \uparrow$。
    • 证明有上界：
      $x_n = (1+\frac{1}{n})^n \cdot \frac{1}{2} \cdot \frac{1}{2} \le \left( \frac{n(1+\frac{1}{n}) + \frac{1}{2} + \frac{1}{2}}{n+2} \right)^{n+2} = \left( \frac{n+2}{n+2} \right)^{n+2} = 4$。
      所以 ${x_n}$ 有上界。
    • 结论：由单调有界定理，${x_n}$ 收敛。记其极限为 $e$（即 $e = \lim_{n \to \infty} (1+\frac{1}{n})^n = 2.71828\dots$，属于 $1^\infty$ 型极限）。
    • 补充：$\log_e a = \ln a$。

3. 递推数列求极限（构造辅助数列法）

例4：设 $a_1 = \sqrt{7}$，$a_2 = \sqrt{7 - \sqrt{7}}$，$\dots$，$a_n = \sqrt{7 - \sqrt{7 + \dots + \sqrt{7}}}$，求 $\lim_{n \to \infty} a_n$。

  • 分析：直接看 $a_n$ 无法判断单调性，构造辅助数列 $b_n$。
  • 令 $b_1 = \sqrt{7}$，$b_2 = \sqrt{7 + \sqrt{7}}$，$\dots$，$b_n = \sqrt{7 + b_{n-1}}$。则 $a_n = \sqrt{7 - b_{n-1}}$。
  • 先证 ${b_n}$ 收敛：
    • 单调性：$b_{n+1} = \sqrt{7 + b_n} \ge b_n \implies b_n \uparrow$。
    • 有界性：用数学归纳法。$b_1 = \sqrt{7} < \frac{1+\sqrt{29}}{2}$。假设 $b_k < \frac{1+\sqrt{29}}{2}$，则 $b_{k+1} = \sqrt{7 + b_k} < \sqrt{7 + \frac{1+\sqrt{29}}{2}} = \sqrt{\frac{15+\sqrt{29}}{2}} = \frac{1+\sqrt{29}}{2}$。
    • 因此 ${b_n}$ 收敛，设极限为 $B$。由 $b_n = \sqrt{7 + b_{n-1}}$ 得 $B = \sqrt{7+B} \implies B^2 - B - 7 = 0$，解得 $B = \frac{1+\sqrt{29}}{2}$（舍负）。
  • 求 $a_n$ 的极限：$\lim_{n \to \infty} a_n = \sqrt{7 - B} = \sqrt{7 - \frac{1+\sqrt{29}}{2}} = \sqrt{\frac{13-\sqrt{29}}{2}}$。

4. 递推数列求极限（A-G不等式及因式分解法）

例5：设 $x_1 = 1$，$x_{n+1} = \sqrt{x_n(3-x_n)}$，求 $\lim_{n \to \infty} x_n$。

  • 证明有界：由 A-G 不等式，$x_{n+1} = \sqrt{x_n(3-x_n)} \le \frac{x_n + (3-x_n)}{2} = \frac{3}{2}$。且 $x_n > 0$（归纳法），所以 $0 < x_n \le \frac{3}{2}$。
  • 证明单调递增：
    $x_{n+1} - x_n = \sqrt{x_n(3-x_n)} - x_n = \frac{x_n(3-x_n) - x_n^2}{\sqrt{x_n(3-x_n)} + x_n} = \frac{2x_n(\frac{3}{2} - x_n)}{\sqrt{x_n(3-x_n)} + x_n} \ge 0$。
    所以 $x_n \uparrow$。
  • 求极限：设 $\lim_{n \to \infty} x_n = A$。由 $x_{n+1} = \sqrt{x_n(3-x_n)}$ 得 $A = \sqrt{A(3-A)} \implies A^2 = 3A - A^2 \implies 2A^2 - 3A = 0$，因为 $x_n > 0$，解得 $A = \frac{3}{2}$。

例6：设 $a_1 = \frac{c}{2}$，$a_{n+1} = \frac{c}{2} + \frac{a_n^2}{2}$（$c \in (0,1]$），求 $\lim_{n \to \infty} a_n$。

  • 单调性：$a_{n+1} - a_n = \left( \frac{c}{2} + \frac{a_n^2}{2} \right) - \left( \frac{c}{2} + \frac{a_{n-1}^2}{2} \right) = \frac{a_n + a_{n-1}}{2} (a_n - a_{n-1})$。
    由于 $a_1 = \frac{c}{2} > 0$，$a_2 = \frac{c}{2} + \frac{c^2}{8} > a_1$，所以 $a_2 - a_1 > 0$。由上式递推可知 $a_{n+1} - a_n > 0$，数列单调递增。
  • 有界性：由 $a_1 < 1$，假设 $a_k < 1$，则 $a_{k+1} = \frac{c}{2} + \frac{a_k^2}{2} < \frac{1}{2} + \frac{1}{2} = 1$。所以 $a_n < 1$。
  • 求极限：设极限为 $A$，$A = \frac{c}{2} + \frac{A^2}{2} \implies A^2 - 2A + c = 0 \implies A = 1 \pm \sqrt{1-c}$。由于 $a_n$ 递增且 $a_1 < 1$，所以取 $A = 1 - \sqrt{1-c}$。

三、 子数列与收敛性（归并性定理）

1. 定义

  • 从原数列 ${a_n}$ 中按原顺序任意抽取无限多项，得到子数列 ${a_{n_k}}$。
  • 性质：$n_1 < n_2 < \dots < n_k < \dots$，且 $n_k \ge k$。

2. 归并性定理

  • 定理：数列 ${a_n}$ 收敛于 $A \iff$ 其任意子列 ${a_{n_k}}$ 都收敛于 $A$。
  • 推论：若存在两个子列收敛于不同的极限，则原数列发散（常用来证明数列发散）。
  • 例7：证明 $x_n = (-1)^{n-1}$ 发散。
    • 取子列 $x_{2n-1} = 1 \to 1$，$x_{2n} = -1 \to -1$。
    • 两者极限不相等，故原数列发散。

3. 利用子列求递推数列极限

例8：设 $x_1 = \sqrt{a} \ (a>1)$，$x_{n+1} = \frac{a+x_n}{1+x_n}$，求 $\lim_{n \to \infty} x_n$。

  • 假设极限存在为 $A$，由 $A = \frac{a+A}{1+A} \implies A^2 = a \implies A = \sqrt{a}$。
  • 理论上需要证明收敛性。可以通过考察 ${x_{2n}}$ 和 ${x_{2n-1}}$ 的收敛性，或直接证明单调有界。

例9：设 $x_1 = 1$，$x_{n+1} = \frac{1}{1+x_n}$，求 $\lim_{n \to \infty} x_n$。

  • 设极限为 $A$，$A = \frac{1}{1+A} \implies A^2 + A - 1 = 0 \implies A = \frac{-1+\sqrt{5}}{2}$。
  • 收敛性证明（压缩映射思想）：令 $A = \frac{\sqrt{5}-1}{2}$。
    $\left| x_n - A \right| = \left| \frac{1}{1+x_{n-1}} - A \right| = \left| \frac{1 - A - A x_{n-1}}{1+x_{n-1}} \right| = \left| \frac{-(1+A)(x_{n-1} - A)}{1+x_{n-1}} \right| \le \frac{\sqrt{5}-1}{2} \left| x_{n-1} - A \right|$。
    递推可得 $\left| x_n - A \right| \le \left( \frac{\sqrt{5}-1}{2} \right)^{n-1} \left| x_1 - A \right| \to 0$（因为 $0 < \frac{\sqrt{5}-1}{2} < 1$）。
    故 $\lim_{n \to \infty} x_n = \frac{\sqrt{5}-1}{2}$。

四、 区间套定理

定理（区间套定理）：若闭区间列 ${ [a_n, b_n] }$ 满足：
① 嵌套性：$[a_1, b_1] \supset [a_2, b_2] \supset \dots \supset [a_n, b_n] \supset \dots$
② 长度趋于零：$\lim_{n \to \infty} (b_n - a_n) = 0$
则存在唯一的 $\xi \in \mathbb{R}$，使 $\xi \in [a_n, b_n]$（$n=1,2,\dots$），且 $\lim_{n \to \infty} a_n = \lim_{n \to \infty} b_n = \xi$。

  • 几何意义：数轴上套着不断缩短的闭区间，最终会“套”住唯一的实数点 $\xi$。它是实数完备性的重要体现。

五、 函数极限的定义

1. 定义（$\epsilon - \delta$ 语言）

设函数 $f(x)$ 在点 $x_0$ 的某个去心邻域内有定义。若存在常数 $A$，$\forall \epsilon > 0$，$\exists \delta > 0$，当 $0 < |x - x_0| < \delta$（或记为 $x \in \mathring{U}(x_0, \delta)$）时，有 $|f(x) - A| < \epsilon$，则称 $A$ 为当 $x \to x_0$ 时 $f(x)$ 的极限，记作：
$$\lim_{x \to x_0} f(x) = A \quad \text{或} \quad f(x) \to A \ (x \to x_0)$$

2. 定义的深度解析与注意事项

  • 几何意义：任意给定一个横向带形区域 $(A-\epsilon, A+\epsilon)$，总能在 $x$ 轴上找到 $x_0$ 的一个去心邻域 $(x_0-\delta, x_0+\delta)$，使得该邻域内的所有函数图像都落在这个带形区域内。即：$A-\epsilon < f(x) < A+\epsilon$。
  • 两个关键点：
    ① $\delta = \delta(\epsilon)$：$\delta$ 是根据 $\epsilon$ 确定的，$\epsilon$ 越小，$\delta$ 通常也越小。
    ② $\delta$ 不唯一：若某 $\delta$ 满足条件，则比它小的任何正数也同样满足条件。
  • 函数在某点的极限与函数在该点是否有定义、以及在该点的函数值是多少完全无关，仅与去心邻域内的值有关。
