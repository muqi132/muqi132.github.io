一、 数列极限的核心性质

1. 有界性

  • 定理：若数列 {xn}\{x_n\}{xn​} 收敛，则 {xn}\{x_n\}{xn​} 一定有界。
  • 证明思路（ϵ−N\epsilon - Nϵ−N 语言）：
    • 设 lim⁡n→∞xn=A\lim_{n \to \infty} x_n = Alimn→∞​xn​=A。取 ϵ0=1\epsilon_0 = 1ϵ0​=1，则 ∃N∈N\exists N \in \mathbb{N}∃N∈N，当 n>Nn > Nn>N 时，有 ∣xn−A∣<1|x_n - A| < 1∣xn​−A∣<1。
    • 利用三角不等式放缩：∣xn∣−∣A∣≤∣xn−A∣<1  ⟹  ∣xn∣<∣A∣+1|x_n| - |A| \le |x_n - A| < 1 \implies |x_n| < |A| + 1∣xn​∣−∣A∣≤∣xn​−A∣<1⟹∣xn​∣<∣A∣+1。
    • 取 M=max⁡{∣x1∣,∣x2∣,…,∣xN∣,∣A∣+1}M = \max\{|x_1|, |x_2|, \dots, |x_N|, |A|+1\}M=max{∣x1​∣,∣x2​∣,…,∣xN​∣,∣A∣+1}，则对所有的 nnn，都有 ∣xn∣≤M|x_n| \le M∣xn​∣≤M。得证。

2. 保号性

  • 定理：若 lim⁡n→∞xn=A>0\lim_{n \to \infty} x_n = A > 0limn→∞​xn​=A>0（或 A<0A < 0A<0），则 ∃N∈N\exists N \in \mathbb{N}∃N∈N，当 n>Nn > Nn>N 时，xn>0x_n > 0xn​>0（或 xn<0x_n < 0xn​<0）。
  • 几何直观：数轴上的点 xnx_nxn​ 最终会落入 AAA 的邻域 (A−ϵ,A+ϵ)(A-\epsilon, A+\epsilon)(A−ϵ,A+ϵ) 中。只要取 ϵ<A\epsilon < Aϵ<A（例如取 ϵ=A/2\epsilon = A/2ϵ=A/2），这个邻域就完全位于正半轴。

3. 不等式性

  • 定理：设 lim⁡n→∞xn=A,lim⁡n→∞yn=B\lim_{n \to \infty} x_n = A, \lim_{n \to \infty} y_n = Blimn→∞​xn​=A,limn→∞​yn​=B，且 A<BA < BA<B，则 ∃N∈N\exists N \in \mathbb{N}∃N∈N，当 n>Nn > Nn>N 时，xn<ynx_n < y_nxn​<yn​。
  • 证明思路：取 ϵ<B−A2\epsilon < \frac{B-A}{2}ϵ<2B−A​，则有 xn<A+ϵ<B−ϵ<ynx_n < A + \epsilon < B - \epsilon < y_nxn​<A+ϵ<B−ϵ<yn​。
  • ⚠️ 重要推论：若当 n>Nn > Nn>N 时 xn≤ynx_n \le y_nxn​≤yn​，则 lim⁡n→∞xn≤lim⁡n→∞yn\lim_{n \to \infty} x_n \le \lim_{n \to \infty} y_nlimn→∞​xn​≤limn→∞​yn​。（注意：此处极限只能取 ≤\le≤，即使原数列严格小于，极限也可能相等。 板书右下角给了一个经典例子：1n<2n\frac{1}{n} < \frac{2}{n}n1​<n2​，但极限均为 0）。

4. 夹逼性

  • 定理：若 xn≤yn≤znx_n \le y_n \le z_nxn​≤yn​≤zn​ 且 lim⁡n→∞xn=lim⁡n→∞zn=A\lim_{n \to \infty} x_n = \lim_{n \to \infty} z_n = Alimn→∞​xn​=limn→∞​zn​=A，则 lim⁡n→∞yn=A\lim_{n \to \infty} y_n = Alimn→∞​yn​=A。
  • 推论：若 xn<yn<znx_n < y_n < z_nxn​<yn​<zn​ 且两边极限均为 AAA，则中间极限也为 AAA。
  • 经典例题（图8）：求 lim⁡n→∞(1n2+1+1n2+2+⋯+1n2+n)\lim_{n \to \infty} \left( \frac{1}{\sqrt{n^2+1}} + \frac{1}{\sqrt{n^2+2}} + \dots + \frac{1}{\sqrt{n^2+n}} \right)limn→∞​(n2+1​1​+n2+2​1​+⋯+n2+n​1​)
    • 放缩：分母全部放大为 n2+n\sqrt{n^2+n}n2+n​，得到下界 nn2+n\frac{n}{\sqrt{n^2+n}}n2+n​n​；分母全部缩小为 n2+1\sqrt{n^2+1}n2+1​，得到上界 nn2+1\frac{n}{\sqrt{n^2+1}}n2+1​n​。
    • 求两端极限：lim⁡n→∞nn2+n=1\lim_{n \to \infty} \frac{n}{\sqrt{n^2+n}} = 1limn→∞​n2+n​n​=1，lim⁡n→∞nn2+1=1\lim_{n \to \infty} \frac{n}{\sqrt{n^2+1}} = 1limn→∞​n2+1​n​=1。
    • 由夹逼定理，原式极限为 1。

二、 极限的四则运算与无穷量

1. 四则运算法则

设 lim⁡n→∞xn=A,lim⁡n→∞yn=B\lim_{n \to \infty} x_n = A, \lim_{n \to \infty} y_n = Blimn→∞​xn​=A,limn→∞​yn​=B，则：

  • ① lim⁡n→∞(xn±yn)=A±B\lim_{n \to \infty} (x_n \pm y_n) = A \pm Blimn→∞​(xn​±yn​)=A±B
  • ② lim⁡n→∞(αxn)=αA\lim_{n \to \infty} (\alpha x_n) = \alpha Alimn→∞​(αxn​)=αA （α\alphaα为常数）
  • ③ lim⁡n→∞(xn⋅yn)=A⋅B\lim_{n \to \infty} (x_n \cdot y_n) = A \cdot Blimn→∞​(xn​⋅yn​)=A⋅B
  • ④ lim⁡n→∞xnyn=AB(B≠0)\lim_{n \to \infty} \frac{x_n}{y_n} = \frac{A}{B} \quad (B \neq 0)limn→∞​yn​xn​​=BA​(B=0)
  • ⑤ lim⁡n→∞xn=A≥0  ⟹  lim⁡n→∞xnkm=Akm(m,k∈N+)\lim_{n \to \infty} x_n = A \ge 0 \implies \lim_{n \to \infty} x_n^{\frac{k}{m}} = A^{\frac{k}{m}} \quad (m, k \in \mathbb{N}^+)limn→∞​xn​=A≥0⟹limn→∞​xnmk​​=Amk​(m,k∈N+)

2. 收敛与发散组合的结论

  • 若 {xn}\{x_n\}{xn​} 收敛，{yn}\{y_n\}{yn​} 发散，则 {xn±yn}\{x_n \pm y_n\}{xn​±yn​} 一定发散。（证明：反证法。若 xn+ynx_n+y_nxn​+yn​ 收敛，则 yn=(xn+yn)−xny_n = (x_n+y_n) - x_nyn​=(xn​+yn​)−xn​ 也应收敛，矛盾）。
  • 若 {xn}\{x_n\}{xn​} 和 {yn}\{y_n\}{yn​} 都发散，则 {xn±yn}\{x_n \pm y_n\}{xn​±yn​} 不一定发散。（反例：xn=n,yn=−nx_n = n, y_n = -nxn​=n,yn​=−n，和为 0，收敛）。

3. 无穷小量与无穷大量

  • 无穷小量：若 lim⁡n→∞xn=0\lim_{n \to \infty} x_n = 0limn→∞​xn​=0，称 {xn}\{x_n\}{xn​} 为无穷小量。例如 {1n},{(−13)n}\{\frac{1}{n}\}, \{(-\frac{1}{3})^n\}{n1​},{(−31​)n}。
  • 无穷大量：∀M>0,∃N∈N,∀n>N:∣xn∣>M\forall M > 0, \exists N \in \mathbb{N}, \forall n > N: |x_n| > M∀M>0,∃N∈N,∀n>N:∣xn​∣>M，记作 lim⁡n→∞xn=∞\lim_{n \to \infty} x_n = \inftylimn→∞​xn​=∞（或 +∞,−∞+\infty, -\infty+∞,−∞）。
  • ⚠️ 核心易错点：无穷大一定无界，但无界不一定无穷大！
    • 反例：xn:1,2,1,3,1,4,1,5…x_n: 1, 2, 1, 3, 1, 4, 1, 5 \dotsxn​:1,2,1,3,1,4,1,5…。这个数列无界，但不是无穷大（因为总有部分项等于1，不会一直大于任意给定的 MMM）。
  • 无穷小与无穷大的关系：
    • lim⁡n→∞xn=0  ⟺  lim⁡n→∞Cxn=∞\lim_{n \to \infty} x_n = 0 \iff \lim_{n \to \infty} \frac{C}{x_n} = \inftylimn→∞​xn​=0⟺limn→∞​xn​C​=∞ （CCC为常数，C≠0C \neq 0C=0）
    • lim⁡n→∞xn=∞  ⟺  lim⁡n→∞Cxn=0\lim_{n \to \infty} x_n = \infty \iff \lim_{n \to \infty} \frac{C}{x_n} = 0limn→∞​xn​=∞⟺limn→∞​xn​C​=0

三、 经典极限计算例题精讲

1. 与取整函数结合的极限

  • 例：已知 lim⁡n→∞an=a\lim_{n \to \infty} a_n = alimn→∞​an​=a，求 lim⁡n→∞[nan]n\lim_{n \to \infty} \frac{[n a_n]}{n}limn→∞​n[nan​]​。
  • 解：利用取整函数性质 x−1<[x]≤xx - 1 < [x] \le xx−1<[x]≤x，得到：
    nan−1<[nan]≤nann a_n - 1 < [n a_n] \le n a_nnan​−1<[nan​]≤nan​
    同除以 nnn：an−1n<[nan]n≤ana_n - \frac{1}{n} < \frac{[n a_n]}{n} \le a_nan​−n1​<n[nan​]​≤an​
    ∵lim⁡n→∞(an−1n)=a−0=a\because \lim_{n \to \infty} (a_n - \frac{1}{n}) = a - 0 = a∵limn→∞​(an​−n1​)=a−0=a，且 lim⁡n→∞an=a\lim_{n \to \infty} a_n = alimn→∞​an​=a。
    ∴\therefore∴ 由夹逼定理，得 lim⁡n→∞[nan]n=a\lim_{n \to \infty} \frac{[n a_n]}{n} = alimn→∞​n[nan​]​=a。

2. 多项式型（∞∞\frac{\infty}{\infty}∞∞​ 型）极限

  • 对于 lim⁡n→∞a0+a1n+⋯+aknkb0+b1n+⋯+bmnm\lim_{n \to \infty} \frac{a_0 + a_1 n + \dots + a_k n^k}{b_0 + b_1 n + \dots + b_m n^m}limn→∞​b0​+b1​n+⋯+bm​nma0​+a1​n+⋯+ak​nk​，只看分子分母最高次幂 kkk 和 mmm：
    • 若 k=mk = mk=m，极限为 akbm\frac{a_k}{b_m}bm​ak​​。
    • 若 k<mk < mk<m，极限为 000。
    • 若 k>mk > mk>m，极限为 ∞\infty∞。
  • 例：lim⁡n→∞3n2+4n−72n2−n+12=lim⁡n→∞3+4/n−7/n22−1/n+12/n2=32\lim_{n \to \infty} \frac{3n^2+4n-7}{2n^2-n+12} = \lim_{n \to \infty} \frac{3 + 4/n - 7/n^2}{2 - 1/n + 12/n^2} = \frac{3}{2}limn→∞​2n2−n+123n2+4n−7​=limn→∞​2−1/n+12/n23+4/n−7/n2​=23​。
  • 例：lim⁡n→∞5n3+3n−14n2−2=∞\lim_{n \to \infty} \frac{5n^3+3n-1}{4n^2-2} = \inftylimn→∞​4n2−25n3+3n−1​=∞。

3. 根式有理化求极限

  • 例：lim⁡n→∞n+3−n−1n+2−n+1\lim_{n \to \infty} \frac{\sqrt{n+3} - \sqrt{n-1}}{\sqrt{n+2} - \sqrt{n+1}}limn→∞​n+2​−n+1​n+3​−n−1​​
  • 技巧：分子分母同乘各自的共轭因式。
    分子有理化：(n+3−n−1)→(n+3)−(n−1)n+3+n−1=4n+3+n−1(\sqrt{n+3} - \sqrt{n-1}) \to \frac{(n+3)-(n-1)}{\sqrt{n+3}+\sqrt{n-1}} = \frac{4}{\sqrt{n+3}+\sqrt{n-1}}(n+3​−n−1​)→n+3​+n−1​(n+3)−(n−1)​=n+3​+n−1​4​
    分母有理化：(n+2−n+1)→(n+2)−(n+1)n+2+n+1=1n+2+n+1(\sqrt{n+2} - \sqrt{n+1}) \to \frac{(n+2)-(n+1)}{\sqrt{n+2}+\sqrt{n+1}} = \frac{1}{\sqrt{n+2}+\sqrt{n+1}}(n+2​−n+1​)→n+2​+n+1​(n+2)−(n+1)​=n+2​+n+1​1​
    原式 =lim⁡n→∞4n+3+n−1⋅(n+2+n+1)=4⋅lim⁡n→∞n+2+n+1n+3+n−1= \lim_{n \to \infty} \frac{4}{\sqrt{n+3}+\sqrt{n-1}} \cdot (\sqrt{n+2}+\sqrt{n+1}) = 4 \cdot \lim_{n \to \infty} \frac{\sqrt{n+2}+\sqrt{n+1}}{\sqrt{n+3}+\sqrt{n-1}}=limn→∞​n+3​+n−1​4​⋅(n+2​+n+1​)=4⋅limn→∞​n+3​+n−1​n+2​+n+1​​
    此时分子分母同除以 n\sqrt{n}n​，极限为 4×1+11+1=44 \times \frac{1+1}{1+1} = 44×1+11+1​=4。

4. 指数型极限

  • 例：lim⁡n→∞qn+2nqn+1+(−3)n+1\lim_{n \to \infty} \frac{q^n + 2^n}{q^{n+1} + (-3)^{n+1}}limn→∞​qn+1+(−3)n+1qn+2n​。
  • 解析：板书上分子分母同除以了 qnq^nqn（这隐含了假设 ∣q∣>3|q| > 3∣q∣>3）。
    得到 lim⁡n→∞1+(2/q)nq+(−3)⋅(−3/q)n\lim_{n \to \infty} \frac{1 + (2/q)^n}{q + (-3) \cdot (-3/q)^n}limn→∞​q+(−3)⋅(−3/q)n1+(2/q)n​。
    因为 ∣q∣>3|q| > 3∣q∣>3，所以 ∣2/q∣<1,∣−3/q∣<1|2/q| < 1, |-3/q| < 1∣2/q∣<1,∣−3/q∣<1，极限为 1/q1/q1/q。
    （注：如果 qqq 的绝对值小于 3，则需要分子分母同除以 (−3)n(-3)^n(−3)n 来求极限，这是这种题目的通用手法：除以底数绝对值最大的那一项）。

5. 重要极限证明：lim⁡n→∞nn=1\lim_{n \to \infty} \sqrt[n]{n} = 1limn→∞​nn​=1

  • 证明：利用之前学过的A-G不等式结论 1≤nn<1+2n1 \le \sqrt[n]{n} < 1 + \frac{2}{\sqrt{n}}1≤nn​<1+n​2​。
  • 由于 lim⁡n→∞1=1\lim_{n \to \infty} 1 = 1limn→∞​1=1 且 lim⁡n→∞(1+2n)=1\lim_{n \to \infty} (1 + \frac{2}{\sqrt{n}}) = 1limn→∞​(1+n​2​)=1，由夹逼定理得证。

6. 重要极限证明：lim⁡n→∞an=1(a>0)\lim_{n \to \infty} \sqrt[n]{a} = 1 \quad (a > 0)limn→∞​na​=1(a>0)

  • 分情况讨论：
    • ① 当 a=1a = 1a=1 时，显然成立。
