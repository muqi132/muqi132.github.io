§1\S1§1 集合与函数

第一部分：集合与逻辑基础（图1、图2、图3）

1. 集合的基本概念

  • 集合的表示：
    • 列举法：A={2,2,3}A = \{2, 2, 3\}A={2,2,3}。（注：老师写这个例子是为了强调集合元素的互异性，实际等价于 A={2,3}A = \{2, 3\}A={2,3}）
    • 描述法：B={高个同学}B = \{\text{高个同学}\}B={高个同学}。
  • 常用数集符号：N\mathbb{N}N (自然数集)，R\mathbb{R}R (实数集)，Q\mathbb{Q}Q (有理数集)，C\mathbb{C}C (复数集)，Z\mathbb{Z}Z (整数集)，R+(R+)\mathbb{R}_+ (\mathbb{R}^+)R+​(R+) (正实数集)，Q+\mathbb{Q}_+Q+​ (正有理数集)。
  • 集合关系与运算：
    • 子集：A⊆BA \subseteq BA⊆B（AAA 是 BBB 的子集）。
    • 交与并：∩\cap∩（交集），∪\cup∪（并集）。

2. 逻辑符号与充要条件

  • 推导符号：⇒\Rightarrow⇒ 表示推导，也代表“必要性”（由 PPP 推出 QQQ 时，PPP 是 QQQ 的充分条件，QQQ 是 PPP 的必要条件）。
  • 充要条件：⇔\Leftrightarrow⇔（等价，即充分必要条件）。
  • 量词符号：∃\exists∃（存在），∀\forall∀（任意），∈\in∈（属于），∉\notin∈/（不属于），ϵ\epsilonϵ（希腊字母 epsilon，常用于表示很小的正数）。
  • 经典例题：设 a,b∈Ra, b \in \mathbb{R}a,b∈R，则 a≤b⇔∀ϵ>0,a<b+ϵa \le b \Leftrightarrow \forall \epsilon > 0, a < b + \epsilona≤b⇔∀ϵ>0,a<b+ϵ。
    • 证明思路：
      • ⇒\Rightarrow⇒（正向）：显然成立（因为 a≤b<b+ϵa \le b < b + \epsilona≤b<b+ϵ）。
      • ⇐\Leftarrow⇐（反向）：使用反证法。假设 a>ba > ba>b，令 ϵ0=a−b2\epsilon_0 = \frac{a - b}{2}ϵ0​=2a−b​ （板书写作取 0<ϵ0<a−b0 < \epsilon_0 < a - b0<ϵ0​<a−b 或 ϵ0=a−b2\epsilon_0 = \frac{a-b}{2}ϵ0​=2a−b​）。此时 b+ϵ0<b+(a−b)=ab + \epsilon_0 < b + (a-b) = ab+ϵ0​<b+(a−b)=a，即 a>b+ϵ0a > b + \epsilon_0a>b+ϵ0​，这与已知条件 ∀ϵ>0,a<b+ϵ\forall \epsilon > 0, a < b + \epsilon∀ϵ>0,a<b+ϵ 矛盾。
    • 推论：a,b∈Ra, b \in \mathbb{R}a,b∈R，若 ∀ϵ>0,∣a−b∣<ϵ⇒a=b\forall \epsilon > 0, |a - b| < \epsilon \Rightarrow a = b∀ϵ>0,∣a−b∣<ϵ⇒a=b。

第二部分：实数系与历史发展（图3、图4、图5）

1. 有理数与无理数

  • 有理数集定义：Q={nm∣n∈Z,m∈Z+,(m,n)=1}\mathbb{Q} = \{ \frac{n}{m} \mid n \in \mathbb{Z}, m \in \mathbb{Z}_+, (m,n)=1 \}Q={mn​∣n∈Z,m∈Z+​,(m,n)=1}。
  • 有理数的性质：
    • 封闭性：四则运算结果仍为有理数。
    • 稠密性：任意两个有理数之间，一定存在另一个有理数。
  • 无理数的发现：
    • 古希腊数学家 Hippasus (希帕索斯) 发现正方形的对角线（2\sqrt{2}2​）无法用两个整数之比表示。
    • Weierstrass (魏尔斯特拉斯)：板书右侧画了一个特殊的函数图像，即魏尔斯特拉斯函数（处处连续但处处不可导），这代表了实数系中极其复杂的函数构造。
  • 连续性：实数充满了整个数轴（无缝隙）。右侧画了零点存在定理（介值定理）的几何直观：f(a)<0,f(b)>0  ⟹  ∃ξ∈(a,b),f(ξ)=0f(a) < 0, f(b) > 0 \implies \exists \xi \in (a,b), f(\xi) = 0f(a)<0,f(b)>0⟹∃ξ∈(a,b),f(ξ)=0。

2. 实数理论基础时间线（图5）

  • 1872年：Dedekind (戴德金) 分割。
  • 1883年：Cantor (康托尔) 实数定义。
  • 1887年：Stolz (施托尔茨) 证明无理数可用不循环小数表示。
  • 1900年：Hilbert (希尔伯特) 提出23个数学问题。
